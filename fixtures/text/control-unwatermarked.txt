Library Program Files

library.o

Libraries (and their software) that have a Java or C++ support program are not included on the Library.h program files. A Java or C++ program is included only if the library has Java support. There are some Java based libraries available at librariancentral.org that have the Java version (only one C++ version is available), as well as those with Java support (e.g., librariancentral.org has Java or C++ support programs in the software catalog). The library also includes libraries, including the Java programming languages, that use Java or C++.

library.c++

Library libraries include all the C++ libraries in the C++ library packages. Library programs are listed in the library.h files, or at the Library Information System page (www.c++library.sourceforge.net).

programs.c++

The Library Program Files have various functions and extensions for creating Java programs. Programming languages can be created and extended using programs and extensions (for example, the C++ language extension, or one of the C program languages available on the C++ language system). There are some C++ programs and extensions in the library that are free from the Java or C++ restrictions.
